Bipartite matching, built step by step

A bipartite graph is G = (A ∪ B, E) where every edge has one endpoint in A and one in B. A matching is a set of edges no two of which share an endpoint. The problem is to find a matching of maximum size.

There is no obvious greedy or DP for this. The move is to turn it into a flow problem, which you already know how to solve.

Turning a matching problem into a flow problem

Four steps to build the network, then read the matching off the middle layer.

Why capacity 1 on the source edges is the matching condition

The capacity of (s, u) is the number of times u is allowed to be used. Flow conservation then forces fout(u) = fin(u) ≤ 1, so at most one middle edge out of u carries flow. That is precisely "u is in at most one matched edge".

The same argument at v, using the capacity of (v, t), handles the other side. The two matching conditions are not enforced by anything clever, they are enforced by two numbers.

The four layer pattern

Nearly every Q5 is the same network with different numbers on it.

The template network 
          cap = per-left limit      cap = 1        cap = per-right limit
    s  ------------------------>  uᵢ  -------->  vⲧ  ------------------------>  t
       (one edge per left thing)  (one edge per   (one edge per right thing)
                                   allowed pair)
  • Left layer: one vertex per thing being assigned (students, workers, TAs, roasters).
  • Right layer: one vertex per thing being assigned to (clubs, jobs, time slots, shops).
  • Middle edges: only for pairs the problem permits. This is where "no student can be assigned to a club they did not apply to" lives.
  • Source edges: carry the per left thing limit.
  • Sink edges: carry the per right thing limit.

The two variations you have to know

A global cap needs a fifth node

If the problem says "exactly c time slots must be filled" or "at most k in total", the cap is not per left thing or per right thing, so it does not fit on any existing edge. Add a node t' just before t, route every sink edge into t', and put a single edge (t', t) with capacity c. Every unit of flow is now forced through that one edge, so it alone enforces the global cap.

Then check f(t', t) = c at the end. If the max flow is less than c, no valid assignment exists and you output that.

Capacity greater than 1 on a middle edge

Capacity 1 on the middle means each pair can be used at most once, which is what "no club can be assigned a student twice" requires. If instead the problem measures a quantity (kilograms of coffee, hours of work), the middle capacity is whatever the pairwise limit is, or infinity if there is none. Read the sentence and put the number on the edge.

Mapping constraints onto edges

This is the actual exam skill: read a paragraph of English, and know which edge each sentence becomes. Try it on the December 2024 clubs question.

Each constraint lives on exactly one edge

Tap a constraint to see where it is enforced in the network.

If a constraint has nowhere to go, your network is wrong

Work through the problem statement sentence by sentence and point at the edge that enforces each one. Any sentence with no edge is a constraint your network does not implement, and your correctness proof will be false. That check takes a minute and is the difference between 15 and 8 on this question.

The reverse also holds: an edge with a capacity you cannot justify from a sentence is an invented constraint, and it may cut off valid assignments.

Image segmentation, where you want the cut and not the flow

Every pixel u has a likelihood au of being foreground and bu of being background. Neighbouring pixels (u,v) have a separation penalty pu,v charged when one goes foreground and the other background. Partition the pixels into foreground A and background B maximising

q(A,B) = ∑u∈A aᵘ  +  ∑u∈B bᵘ  -  ∑(u,v) separated pᵘ,ᵛ
The trick: turn a maximisation into a minimisation

The total ∑u(au + bu) is a constant, independent of how you partition. Subtract q from it and the maximisation becomes a minimisation of

q'(A,B) = ∑u∈B aᵘ  +  ∑u∈A bᵘ  +  ∑(u,v) separated pᵘ,ᵛ

Notice the a and b swapped sides and the penalty flipped sign. Now every term is a cost paid for a separation, which is exactly the shape of a cut capacity.

The network
  • (s, u) with capacity au, for every pixel u. Cut when u lands in B, charging au.
  • (u, t) with capacity bu, for every pixel u. Cut when u lands in A, charging bu.
  • (u,v) and (v,u) each with capacity pu,v, for every neighbouring pair. Cut when u and v land on opposite sides.

Then c(A,B) = q'(A,B) for every s-t cut, so a minimum cut is an optimal segmentation. Find it by computing a max flow and taking the vertices reachable from s in the residual.

The generalisable idea

The source side of a cut becomes one label and the sink side the other, so an s-t cut is a binary labelling of the vertices. If your objective can be written as a sum of penalties, each charged when a specific pair gets different labels, then min cut solves it. That is why this trick shows up in project selection and survey design as well as segmentation.

The two direction correctness proof

Both directions are required. Each is worth marks, and each is three or four sentences.

Direction 1: assignment gives flow

"Let M be a valid assignment of size k. Define a flow f by putting 1 unit on (ui, vj) for each assigned pair, and setting f(s, ui) to the number of assignments of i and f(vj, t) to the number of assignments to j. Conservation holds by construction. Capacities are respected because [each constraint of the problem, named]. Hence f is a valid flow of value k, so max flow ≥ max assignment."

Direction 2: flow gives assignment

"Conversely, let f be an integral maximum flow of value k, which exists because all capacities are integers and Ford Fulkerson returns an integral flow. Since middle edge capacities are 1, each f(ui, vj) is 0 or 1. Assign i to j exactly when it is 1. Conservation at ui gives that i is assigned at most c(s, ui) times, and conservation at vj gives that j receives at most c(vj, t). A middle edge exists only for permitted pairs. So the assignment is valid and has size k, giving max assignment ≥ max flow."

"The two inequalities together give equality, so the algorithm's output is optimal."

Do not skip the second direction

Showing only that assignments give flows proves max flow ≥ max assignment, which says nothing useful: a flow could be larger and correspond to no assignment at all. The second direction is the one that makes the algorithm correct, and it is the one that needs integrality.

Exam answer, written out

December 2024 Q5. There are m students and n clubs. Each student is in at most b clubs. Club ci accepts at most ki members. Student i applied to the set Ai. Maximise total club membership. Give the algorithm, justify correctness, and bound the running time by a polynomial in n + m.

Think about it first, then open this

The network. Construct G = (V, E) where V consists of a source s, a sink t, a vertex ui for each student si, and a vertex wj for each club cj. The edges are:

  • (s, ui) with capacity b, for each i ∈ [m];
  • (ui, wj) with capacity 1, for each i and each cj ∈ Ai;
  • (wj, t) with capacity kj, for each j ∈ [n].

The algorithm. Compute an integral maximum s-t flow f in G using Ford Fulkerson with the shortest augmenting path rule. Then assign student i to club j exactly when f(ui, wj) = 1. Output that assignment.

Correctness.

Every valid assignment of total size k yields a flow of value k. Given such an assignment, put 1 unit on (ui, wj) for each assigned pair, set f(s, ui) to the number of clubs student i was assigned, and f(wj, t) to the size of club j. Conservation holds at every ui and wj by construction. The source edge capacity is respected because each student is in at most b clubs; the middle edge capacities are respected because a student is assigned to a club at most once, and edges exist only for clubs applied to; the sink edge capacities are respected because club j takes at most kj members. The value of this flow is fout(s), which equals the total number of assignments, that is, the total membership k.

Every integral flow of value k yields a valid assignment of total size k. All capacities are integers, so Ford Fulkerson returns an integral flow, meaning each f(ui, wj) ∈ {0, 1}. Take the assignment defined above. No student is assigned to a club twice, since that edge carries at most 1. No student is assigned a club they did not apply to, since no such edge exists. Student i is assigned fout(ui) = fin(ui) = f(s, ui) ≤ b clubs. Club j receives fin(wj) = f(wj, t) ≤ kj students. The total membership equals ∑j f(wj, t) = fin(t) = val(f) = k.

The two directions give a bijection between valid assignments and integral flows that preserves size, so maximising the flow maximises total membership.

Running time. Let L = ∑i|Ai| ≤ mn be the total number of applications. Then |V| = m + n + 2 and |E| = m + L + n. Building the network takes O(m + n + L). Edmonds Karp runs in O(|E|2|V|) = O((m + n + L)2(m + n)). Reading off the assignment takes O(|E|). The total is dominated by the flow computation and is polynomial in n + m, since L ≤ mn.

The move to notice

Every number in the problem statement ended up on exactly one edge, and no edge got a capacity that was not in the problem statement. When that is true, the correctness proof is nearly mechanical, because each capacity check in the proof is just quoting the sentence it came from.

Recognising Q5 in 60 seconds
  • Two kinds of thing, and you are pairing them up.
  • Limits on both sides ("each student at most b", "each club at most kᵢ").
  • A permitted-pairs relation ("applied to", "qualified for", "available at").
  • "Maximise the number of assignments" or "decide if a valid assignment exists".

Then: four layers, capacities from the two limits, middle edges from the relation, integrality sentence, both directions, Edmonds Karp bound. Write those six things and the question is done.
