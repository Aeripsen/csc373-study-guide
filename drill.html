Warm up: master theorem, 8 minutes

Write the tightest bound following from the master theorem. No justification needed, but write the one line reason for yourself.

RecurrenceYour answer
$T(n) \le 3T( \lceil n/2 \rceil ) + O(n log n)$
$T(n) \le 8T( \lceil n/2 \rceil ) + O(n^{2})$
$T(n) \le 8T( \lceil n/2 \rceil ) + O(n^{3})$
$T(n) \le 2T( \lceil n/4 \rceil ) + O( \sqrt n)$
Answers
  1. $O(n^{log_{2}3})$. Here $c = log_{2}3 \approx 1.585$. Since $n log n = O(n^{1+ \epsilon })$ for any $\epsilon > 0$, and $log_{2}3 > 1$, we are in case 1 and the log vanishes.
  2. $O(n^{3})$. $c = log_{2}8 = 3$ and $n^{2} = n^{3-1}$, so case 1.
  3. $O(n^{3} log n)$. c = 3 and $n^{3} = \Theta (n^{3})$, so case 2 with k = 0.
  4. $O(n^{1/2} log n)$. $c = log_{4}2 = 1/2$ and $f(n) = \sqrt n = \Theta (n^{1/2})$, a tie, so case 2 with k = 0.
Watch the difference between 4 and the version with O(n)

T(n) = 2T(n/4) + O(n) gives O(n), not O(n log n), because $n = n^{0.5 + 0.5}$ is polynomially larger than $n^{0.5}$, so it is case 3, not case 2. Also check the regularity condition: $af(n/b) = 2(n/4) = n/2 = \tfrac{1}{2} f(n)$, so $d = \tfrac{1}{2} < 1$ works.

Q1. Divide and conquer: significant inversions 20 marks · 25 min

Recall counting inversions: pairs i < j with A[i] > A[j], solvable in O(n log n). A significant inversion is a pair i < j with A[i] > 2A[j]. For example A = [6, 2, 1, 3] has 4 inversions but only 2 significant ones. Modify the algorithm from class to count significant inversions in O(n log n). Justify correctness and running time.

Hint

The comparison you count with is not the comparison you sort with. What does that force you to do?

Model answer

Algorithm. Implement CountSig(A, l, u) which returns the number of significant inversions inside A[l..u], together with A[l..u] in sorted order. The top level calls CountSig(A, 1, n) and outputs the count.

Base case: if l == u, return (0, A[l..u]).

Otherwise let $mid = \lfloor (l+u)/2 \rfloor$, and recursively compute (L, left) = CountSig(A, l, mid) and (R, right) = CountSig(A, mid+1, u). Both returned halves are sorted.

To count the straddling pairs C, make a copy B of right and double every entry. Run the merge-and-count procedure from class on left and B, which counts pairs (i, j) with left[i] > B[j]. Since $B[j] = 2 \cdot right[j]$, those are exactly the pairs with $left[i] > 2 \cdot right[j]$, that is, the significant straddling inversions.

Then run a second, ordinary merge of left and right to build the sorted output. Return (L + R + C, merged).

Correctness. By induction on n = u - l + 1. The base case is immediate, as a single element contains no pairs. For the step, L and R correctly count the significant inversions lying wholly in the left and wholly in the right half, by the induction hypothesis. Every significant inversion is in exactly one of three groups: both indices left, both right, or straddling. So it remains to show C counts the straddling group.

The merge-and-count procedure from class correctly counts, for two sorted arrays, the pairs with first[i] > second[j]. It applies here because left is sorted by the induction hypothesis and B is sorted, since doubling is monotone and right is sorted. And $left[i] > B[j] \iff left[i] > 2 \cdot right[j]$. So C is exactly the straddling count. The sorted output is correct by the correctness of the mergesort merge.

Running time. Doubling the copy is O(n), the counting merge is O(n), and the plain merge is O(n), so the combine step is O(n) overall. Hence T(n) = 2T(n/2) + O(n). By the master theorem with a = 2, b = 2, c = log₂2 = 1, and $f(n) = \Theta (n) = \Theta (n^{c})$, we are in case 2 with k = 0, giving T(n) = O(n log n).

The idea worth keeping

Two merges, not one. The doubled array is right for counting and wrong for sorting. Whenever the comparison used to count differs from the comparison used to order, you need separate passes, and since each is O(n), the recurrence does not change.

Q2. Divide and conquer: majority in a ternary tree 20 marks · 25 min

A complete ternary rooted tree: every non leaf node v has exactly three children c[v], and every leaf v has a positive integer x[v]. For each non leaf node, decide whether some value is associated with a strict majority of the leaves in its subtree. Output Y or N per non leaf node. Give pseudocode, justify correctness, and analyse the running time in terms of the total number of nodes n.

Hint

If a value is a strict majority in a subtree, must it be a strict majority in at least one of the three child subtrees? Why does that give you at most three candidates to test?

Model answer

Algorithm. Declare c, x and an output array maj[1..n] initialised to N as globals, then call MajRec(r) on the root.

MajRec(v)
1  if c[v] is empty
2      return x[v]                        // v is a leaf
3  T = number of leaves in the subtree of v      // one traversal
4  for each child v' of v
5      z = MajRec(v')
6      if z is not None and count of z among the leaves of v's subtree > T/2
7          maj[v] = Y
8          return z
9  return None

MajRec(v) returns a majority value in v's subtree if one exists, and None otherwise.

Correctness. We argue that MajRec(v) returns a majority value of v's subtree when one exists and None otherwise, setting maj[v] accordingly.

For a leaf, the subtree has one leaf, so its value is trivially a strict majority, and line 2 returns it. Nothing needs to be recorded, since leaves are not asked about.

For a non leaf v, the key fact is this: if z is a strict majority among the leaves of v's subtree, then z is a strict majority in at least one child's subtree. Suppose not. Then z appears at most half the leaves in each of the three child subtrees, so summing over the children z appears at most half of all leaves, contradicting strict majority. Also a strict majority is unique, since two distinct values each on more than half the leaves would need more than all of them.

So if a majority exists, it appears among the (at most three) values returned by the recursive calls, and line 6 tests each candidate against the true count. Some test succeeds, so maj[v] = Y and z is returned. If no majority exists, then no candidate passes the test, every check on line 6 fails, and the algorithm correctly returns None with maj[v] left at N.

Running time. Let T(n) be the time on a node whose subtree has n nodes. The algorithm recurses on three children, each with a subtree of at most n/3 nodes, and spends O(n) time on lines 3 and 6: counting the leaves and counting occurrences of at most three candidate values can each be done by a single linear traversal (BFS or DFS) of the subtree. Hence

T(n) ≤ 3T(n/3) + O(n)

By the master theorem with a = 3, b = 3, c = log₃3 = 1, and $f(n) = \Theta (n)$, we are in case 2 with k = 0, so T(n) = O(n log n).

Q3. Greedy: books on shelves 20 marks · 25 min

Store n books, numbered 1 to n, on shelves. Each shelf holds consecutively numbered books of total thickness at most L. Given T[1..n] and L, minimise the number of shelves. Give pseudocode and words, analyse the running time (O(n) for full credit), then prove optimality.

Model answer

Algorithm. Fit as many books as possible on shelf 1, then as many of the rest as possible on shelf 2, and so on.

GreedyShelves(T, L)
1  P[0] = 0
2  for i = 1 to n
3      P[i] = P[i-1] + T[i]           // prefix sums
4  num = 1
5  s = 1
6  for t = 2 to n
7      if P[t] - P[s-1] > L
8          output shelf num with books s, ..., t-1
9          num = num + 1
10         s = t
11 output shelf num with books s, ..., n

Running time. Two loops of at most n iterations, constant work each, so O(n).

Optimality. First note what the algorithm computes: P holds prefix sums, so P[t] - P[s-1] is the total thickness of books s..t. The shelf starting at s therefore holds books s, ..., t-1 where t is the first index making that sum exceed L. An easy induction shows each shelf holds the maximum number of consecutive books of total thickness at most L, starting from the first book not yet shelved.

We prove by induction on i that shelves 1 through i of the greedy solution are also shelves of some optimal solution O.

Base case. i = 0, trivial.

Inductive step. Assume shelves 1 through i-1 of greedy are shelves of an optimal O. If greedy's shelf i is also a shelf of O, done. Otherwise, let s and t be the first and last books on greedy's shelf i. Since shelves 1 through i-1 agree, both solutions have shelved exactly books 1..s-1, so book s is the first book on shelf i of O too. Shelf i of O therefore holds books s, ..., t' for some $t' \le t$ by the greedy choice (greedy fits the maximum possible), and since the shelves differ, t' < t.

Move books t'+1, ..., t from their shelves in O onto shelf i of O. They fit, because they fit together with books s..t' on greedy's shelf i. The number of shelves does not increase, since we only moved books later in the order onto an earlier shelf, so O remains optimal, and now shelf i matches greedy's. This completes the step.

Conclusion. The greedy solution's shelves all appear in some optimal solution O, and since greedy shelves every book, O has no further shelves. So greedy uses the same number of shelves as O and is optimal.

Q4. Greedy: partitioning a line of couples 20 marks · 25 min

There are n couples, and all 2n people stand in a line. A[1..2n] gives the couple index of each person. A segment is good if everyone in it has their partner in it too. Compute the maximum number of good segments the line can be partitioned into. O(n) for full credit. Then prove correctness.

Hint

Scan left to right tracking how many couples you have seen exactly one member of. What does it mean when that count reaches zero?

Model answer

Algorithm.

MaxSegments(A)
1  B[1..n] = False           // couples seen once but not twice
2  cnt = 0                   // how many such couples
3  segs = 0
4  for i = 1 to 2n
5      if B[A[i]] == False
6          B[A[i]] = True,  cnt = cnt + 1
7      else
8          B[A[i]] = False,  cnt = cnt - 1
9          if cnt == 0
10             segs = segs + 1
11 return segs

In words. B[j] records whether couple j is "half seen". cnt is how many couples are half seen. Reading left to right, the first member of a couple opens it and the second closes it. When cnt hits 0, every couple encountered so far is complete and no later couple has been touched, so we have found a minimal good segment and we cut there.

Running time. Each of the 2n people is processed in O(1) time, so O(n).

Correctness. By induction on the number of couples n.

Base case. n = 1, two people, one segment, clearly optimal.

Inductive step. Assume the algorithm is correct on every instance with fewer than n couples. Take an optimal solution OPT for an instance A with n couples, and suppose its first segment is {1, ..., i}. Being good, it fully contains i/2 couples and no member of any other couple. So after the algorithm processes person i, every couple is either fully seen or fully unseen, meaning B is entirely False and cnt = 0. Since the algorithm increments segs every time cnt drops to 0, it has produced at least one segment by position i.

The remainder A[i+1 .. 2n] is a valid instance with n - i/2 couples, and the algorithm enters it in exactly its initial state (B all False, cnt = 0). By the induction hypothesis it produces the maximum possible number of good segments on that remainder, hence at least as many as OPT does there.

Adding up, the algorithm produces at least as many segments as OPT overall, so it is optimal.

An alternative that also gets full marks

Define greedy's partial solution up to person i to be promising if its segment endpoints so far match those of some optimal solution, then induct on i. Both work here, because this problem has a unique optimal partition. Say which induction you are doing in your first line.

Q5. Dynamic programming: dominoes on an array 20 marks · 25 min

You have unlimited dominoes of k types, type j being an ordered pair $(a_{j}, b_{j})$. Given C[1..n], a domino of type j can go on indices (i, i+1) when $a_{j} = C[i]$ and $b_{j} = C[i+1]$. Maximise the number of non overlapping dominoes. O(nk) for full credit, O((n+k) log k) for bonus.

Model answer

(a) The table. For i = 1, ..., n, let dom[i] be the maximum number of non overlapping dominoes placeable on the subarray C[1..i]. Set dom[0] = 0. The final answer is dom[n].

(b) The Bellman equation.

dom[i] = 0                                     if i ≤ 1
dom[i] = max{ dom[i-1], dom[i-2] + 1 }         if i ≥ 2 and some type j
                                               has (C[i-1], C[i]) = (aⲧ, bⲧ)
dom[i] = dom[i-1]                              otherwise

Justification. For $i \in {0, 1}$ there are not two cells, so no domino fits and the answer is 0. For $i \ge 2$, consider an optimal placement on C[1..i] and ask whether cell i is covered. If it is, the covering domino must sit on (i-1, i), which requires a type matching (C[i-1], C[i]), and the rest is an optimal placement on C[1..i-2], giving dom[i-2] + 1. If cell i is uncovered, the placement is an optimal one on C[1..i-1], giving dom[i-1]. These cases are exhaustive, so the optimum is the larger. When no type matches, the first case is impossible and only dom[i-1] remains.

(c) Bottom up. Compute in the order i = 0, 1, ..., n. Base cases dom[0] = dom[1] = 0 are set directly. For each $i \ge 2$, the only real work is testing whether (C[i-1], C[i]) matches one of the k types.

The straightforward version scans all k types per cell, giving O(nk).

Bonus, O((n+k) log k). Pre-process the domino types once into a balanced search structure keyed by the pair, costing O(k log k) for k insertions. Each lookup is then O(log k). Alternatively, sort the types by $a_{j}$ breaking ties by $b_{j}$ in O(k log k), then per cell binary search for the range with first coordinate C[i-1] and binary search inside it for second coordinate C[i], again O(log k).

Total: O(k log k) pre-processing plus O(log k) for each of n cells, so O((n + k) log k).

Also worth knowing

A greedy that scans left to right and places a domino as soon as it can also solves this optimally, with the same running time. The DP is asked for because it is the robust method, but noticing the greedy works is a good sanity check that your recurrence is right.

Q6. Dynamic programming: counting bundlings 10 marks · 15 min

Given n, count the ways to write $n = i_{1} + i_{2} + ... + i_{k}$ with $i_{1} \ge i_{2} \ge ... \ge i_{k} \ge 1$. For n = 5 the answer is 7. Define P[m, b] as the number of such sums for m with largest part at most b. Give a recurrence with base cases, justify it, then give O(n2) pseudocode.

Model answer

Recurrence.

P[m, b] = 1 + P[m, m-1]              if b ≥ m
P[m, b] = P[m-b, b] + P[m, b-1]      if b < m

base cases:  P[1, b] = 1  for all b ≥ 1
             P[m, 1] = 1  for all m ≥ 1

Justification. Since all parts are positive, $i_{1} \le m$ always, so any bound b > m is no restriction and P[m, b] = P[m, m]. That handles $b \ge m$ once we know P[m, m] = 1 + P[m, m-1], which holds because there is exactly one sum using the single part m, and every other sum has largest part at most m - 1.

For b < m, split on the largest part. Either $i_{1} = b$, and the rest is a sum for m - b with parts at most b, of which there are P[m-b, b]; or $i_{1} \le b - 1$, giving P[m, b-1]. These are exhaustive and disjoint, so add them.

The base cases are immediate: m = 1 has only 1 = 1, and b = 1 forces all parts to be 1, so only m = 1 + ... + 1.

Pseudocode.

1  P[1, b] = 1 for all b;  P[m, 1] = 1 for all m
2  for m = 2 to n
3      for b = 2 to n
4          if b ≥ m
5              P[m, b] = 1 + P[m, m-1]
6          else
7              P[m, b] = P[m-b, b] + P[m, b-1]
8  return P[n, n]

Running time. $n^{2}$ cells, O(1) each, so O(n2), assuming the arithmetic is constant time.

The cleaner version

With base cases P[0, b] = 1 for all $b \ge 0$ and P[m, b] = 0 for m < 0, the single equation P[m, b] = P[m-b, b] + P[m, b-1] covers every case. Shorter, but the case split above is easier to justify under exam pressure, and the justification is what carries the marks.

Q7. Flow: is this flow optimal? 10 marks · 15 min

You are given a flow network with a flow f marked as flow / capacity on each edge. Draw the residual network. Then either show f is not maximum by listing an augmenting path, or show it is maximum by giving an s-t cut whose capacity equals val(f).

The procedure to follow, every time

1. Draw the residual. For each edge with f / c:

  • a forward edge with residual c - f, if positive;
  • a backward edge in the opposite direction with residual f, if positive.

Do not skip the backward ones. They are where the augmenting path usually is.

2. BFS from s in the residual. Mark every vertex you can reach.

3a. If you reach t, f is not maximum. List the path as a node sequence, for example s, b, d, a, c, t. State its bottleneck if asked. Multiple correct answers usually exist, so any valid path earns the marks.

3b. If you cannot reach t, f is maximum. Let A be everything you reached and B = V \ A. Write both sets out. Then compute c(A, B) by summing capacities of edges from A to B, and state that it equals val(f).

4. Check. Compute $val(f) = f^{out}(s)$ independently and confirm it matches your cut capacity. If it does not, you missed an augmenting path or mis-summed the cut.

Why "reachable from s" is the answer to "give a cut"

When BFS stops, every edge leaving A is full (or it would have let you go further) and every edge entering A is empty (or its backward residual edge would have). So the flow across the cut is exactly its capacity, with nothing flowing back. A flow that saturates some cut cannot be beaten, because every flow is bounded by every cut.

And if it asks whether the min cut is unique

Compute the other extreme cut: let B' = the vertices that can reach t in the residual, and A' = V \ B'. That is also a minimum cut. If $A \ne A'$ you have two distinct minimum cuts and you write both. If they are equal, the minimum cut is unique and you say why: no other partition achieves the same capacity.

Q8. LP: coffee roasters and shops 12 marks · 15 min

m roasters, n coffeeshops. Roaster $r_{i}$ supplies at most $s_{i}$ kg per month. Shop $c_{j}$ receives at most $d_{j}$ kg. Shop j values a kg from roaster i at $w_{i,j}$. Every roaster can ship to every shop. (a) Write an LP in standard form maximising total value. (b) Give its dual, saying which dual variable goes with which primal constraint.

Model answer

(a) The primal. Let $x_{i,j} \ge 0$ be the kilograms per month sent from roaster i to shop j.

max   ∑ᵢ₊₁..ᵐ ∑ⲧ₊₁..ₙ  wᵢ,ⲧ xᵢ,ⲧ

s.t.  ∑ⲧ₊₁..ₙ  xᵢ,ⲧ  ≤  sᵢ        for all i ∈ [m]
      ∑ᵢ₊₁..ᵐ  xᵢ,ⲧ  ≤  dⲧ        for all j ∈ [n]
      xᵢ,ⲧ ≥ 0                     for all i, j

This is already in standard form: a maximisation, all constraints $\le$, all variables non negative. Say that explicitly rather than leaving the marker to check.

(b) The dual. There are m + n primal constraints, so m + n dual variables. Use $y_{i}$ for the supply constraint of roaster i, and $z_{j}$ for the demand constraint of shop j. There are mn primal variables, so mn dual constraints, one for each pair (i, j).

min   ∑ᵢ₊₁..ᵐ sᵢ yᵢ  +  ∑ⲧ₊₁..ₙ dⲧ zⲧ

s.t.  yᵢ + zⲧ  ≥  wᵢ,ⲧ         for all i ∈ [m], j ∈ [n]
      yᵢ, zⲧ  ≥  0               for all i, j

The dual constraint for the pair (i,j) reads down the column of $x_{i,j}$, which has a 1 in roaster i's supply row, a 1 in shop j's demand row, and zeros elsewhere. Hence the left hand side $y_{i} + z_{j}$.

What the dual means here

$y_{i}$ is a price per kg charged for using roaster i's capacity, and $z_{j}$ a price per kg for using shop j's. The constraint says the combined price of a shipment must be at least its value, and the objective minimises the total cost of pricing all the capacity. Duality says the cheapest such pricing equals the maximum achievable value. Reading a dual as prices on the primal's scarce resources works for most LPs in this course and makes the algebra much easier to remember.

Q9. NP: certificates and certifiers 8 marks · 8 min

For each problem, give a certificate for a Yes instance and a polynomial time certifier. You do not need to justify the certifier's correctness or running time.

  1. Dominating Set: given G = (V,E) and k, is there a set S of at most k vertices such that every vertex is in S or has a neighbour in S?
  2. 3-Colouring: given G = (V,E), can each vertex get a value in {1,2,3} so no edge has both endpoints equal?
  3. Degree Bounded Spanning Tree: given G = (V,E) and k, is there a spanning tree in which every vertex has degree at most k?
  4. 3-Clique asks whether G contains a triangle. Justify why 3-Clique is in P.
Model answer
  1. The certificate is S. The certifier checks that $|S| \le k$, and that for every $u \in V$, either $u \in S$ or some neighbour of u is in S.
  2. The certificate is the assignment $\varphi : V \to {1,2,3}$. The certifier checks that $\varphi (u) \ne \varphi (v)$ for every $(u,v) \in E$.
  3. The certificate is the edge set of the tree T. The certifier runs DFS in T to check it is connected, by confirming every vertex is visited. It counts the edges of T and checks there are exactly |V| - 1, which together with connectivity rules out cycles. It then computes each vertex's degree within T and checks it is at most k.
  4. There are only $O(n^{3})$ possible certificates, one per triple of vertices, so instead of guessing you can enumerate. Loop over all triples in $O(n^{3})$ time and check in O(1) whether all three pairs are edges, using an adjacency matrix (buildable from an adjacency list in $O(n^{2})$). This decides 3-Clique in $O(n^{3})$ time, so it is in P.
The lesson in part 4

A problem is in NP when a certificate is short. It is in P when the number of possible certificates is only polynomial, so you can try them all. Fixing k to a constant in k-Clique shrinks C(n,k) from exponential to $O(n^{k})$, which is why the general problem is NP complete and the k = 3 case is easy.

Q10. Exchange argument: independent set in a tree 12 marks · 18 min

(a) Let T be a tree and ℓ a leaf. Prove there is a maximum cardinality independent set containing ℓ. (b) GreedyIS(G) repeatedly picks a smallest degree vertex u, removes u and its neighbours, and recurses. Prove GreedyIS(T) returns a maximum independent set for any tree T. You may assume the root has at least two children unless T has 2 or fewer nodes.

Model answer

(a) Let O be a maximum independent set in T. If $ℓ \in O$, done. Otherwise O must contain the parent u of ℓ: if it did not, then $O \cup {ℓ}$ would still be independent (since u is ℓ's only neighbour) and strictly larger, contradicting maximality.

Set $O' = (O \setminus {u}) \cup {ℓ}$. Then |O'| = |O|. And O' is independent: ℓ's only neighbour is u, which we removed, so ℓ conflicts with nothing in O'; and any edge with both endpoints in O' \ {ℓ} would have both endpoints in O, contradicting O being independent. So O' is a maximum independent set containing ℓ.

(b) We prove the stronger statement that the algorithm is correct on forests, that is, acyclic undirected graphs, by induction on the number of vertices n. This is needed because deleting vertices from a tree can disconnect it, and a forest is what you are left with.

Let T' be the connected component of G containing the chosen vertex u. Note that a union of maximum independent sets, one per component, is a maximum independent set of the whole graph, so to show u lies in some maximum independent set of G it suffices to show it lies in one of T'.

u is a leaf of T'. If T' has one or two vertices this is trivial. Otherwise, root it at a vertex with at least two neighbours. Every internal node then has degree at least 2, having a parent and at least one child, and the root has degree at least 2 by assumption. A leaf has degree 1. Since the algorithm picks a vertex of smallest degree, it picks a leaf.

By part (a), some maximum independent set of T' contains u, and hence some maximum independent set O of G contains u.

Since O is independent and contains u, it contains no neighbour of u. So O' = O \ {u} is an independent set in G', the graph after removing u and its neighbours. Deleting vertices from a forest leaves a forest, so the induction hypothesis applies to G', giving $|S'| \ge |O'|$ where S' is what the recursive call returns. Therefore

|S| = |S'| + 1 ≥ |O'| + 1 = |O|

and S is a maximum independent set in G.

Why the proof had to generalise to forests

The induction hypothesis is applied to G', and G' is what remains after deleting a vertex and its neighbours, which is usually disconnected. A hypothesis only about trees could not be applied to it. Strengthening the claim to forests makes the induction go through, and it is easier to prove because deleting vertices cannot create a cycle. Strengthening the statement to make an induction work is a standard move and is worth recognising.

Two pieces of advice that came with the list

Do the solved exercises. Kleinberg and Tardos put two fully solved exercises at the end of every chapter. They are the closest thing in either book to a model exam answer, and they are worth more per minute than the unsolved ones.

Sample widely rather than grinding one chapter. The instructor noted there is a real chance some textbook exercises turn up on a test, so breadth across all three books beats depth in one.

Mark it honestly

Give yourself marks only for what you actually wrote, not for what you meant. In particular, no marks for an unstated running time, a missing base case, a one directional correctness proof, or a reduction with no reverse direction. Those four are where almost everyone loses marks they thought they had.
