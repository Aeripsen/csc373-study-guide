Every model solution in this course has a visible skeleton. The marker is looking for specific moves, and the moves are the same whatever the story in the question is. What follows is each skeleton written out, with the sentences you can write before you have solved anything.

The clock and the order of attack

3 hours, 90 marks. That is exactly 2 minutes a mark, which sounds generous and is not, because Q3 and Q5 will eat more than their share. Do the mechanical questions first: they bank marks at high speed and they warm you up.

Time budget

Tap a question to see what it costs you. Switch the order to see why doing the paper front to back is a mistake.

180 minutes total. The recommended order front loads the two questions with nothing to invent, so 20 marks are safe before you meet a hard one.
Why this order

Q4 and Q6 have no design step. You either know the procedure or you do not, and knowing it takes under 30 minutes combined. Doing them first means that if you then get stuck on Q5 for 40 minutes, you have already passed the 40% bar and the panic is survivable. Doing the paper in order means Q1, a design question, decides your mood for the next two hours.

Q1 skeleton: divide and conquer 15 marks · 25 min

The question always states the target running time, and it is nearly always O(n log n). That tells you the recurrence before you have read the problem: two halves, linear merge.

Template

1. State the contract. One sentence, and it is worth writing first because everything else depends on it.

"We implement a procedure Solve(A, l, u) which returns [exactly what it returns] for the subarray A[l..u]. The algorithm calls Solve(A, 1, n) and outputs [the answer]."

2. Pseudocode. Numbered lines. Base case first, then split, then two recursive calls, then the combine step.

3. Explain the combine step in words. This is where the marks are. The split and the recursion are trivial. Say precisely what work the merge does and why it is linear.

4. Correctness. "We prove correctness by induction on n. The base case n = 1 is immediate since [...]. For the inductive step, assume the recursive calls return correct answers for the two halves. Then [...] so the combine step produces the correct answer for A[l..u]."

5. Running time. "The two recursive calls are on inputs of size n/2, and the combine step takes O(n) time, so T(n) ≤ 2T(n/2) + O(n). By the master theorem with a = 2, b = 2, c = log22 = 1 and f(n) = O(n) = Θ(nc), this gives T(n) = O(n log n)."

The two extras that come up constantly

Sort first. If the input is unsorted and you need it sorted, say "we first sort in O(n log n), which does not change the overall bound" and move on. Do not fold sorting into the recursion by accident.

Return two things. The counting inversions algorithm returns the count and the sorted array. If your combine step needs sorted halves, your recursive procedure has to promise to sort. Say so explicitly in the contract, or the correctness proof has a hole.

Pseudocode or a written description?

Course staff have answered this directly: write pseudocode if you have the time. Marking on the exam is more relaxed about the level of detail than marking on the assignments, so a clear prose description that contains all the relevant details and the main ideas will also earn the marks.

The practical reading: pseudocode is faster to write and harder to be vague in, so default to it. If you are running out of time, a precise paragraph beats half a page of half-finished pseudocode. What you cannot do is be vague, in either format.

Q2 skeleton: dynamic programming 15 marks · 25 min

This question is split into three parts and they are marked separately, which is a gift. Part (a) is 2 or 3 marks for one sentence. Never leave it blank, even if you cannot do (b) and (c).

Template, part (a): define the array

Three things, no more:

"For i = 0, 1, ..., n define A[i] to be the maximum [quantity] achievable using only [the first i items / a budget of i]. We also define A[0] = 0. The final answer is A[n]."

Say what the index ranges over, say what the entry holds in words (not as a formula), and say which entry is the answer. If the array is two dimensional, do it for both indices.

Template, part (b): the Bellman equation

1. Write the recurrence, with the base cases labelled as base cases.

2. Justify it with the case split. The justification is always the same two sentences, rewritten for the problem:

"Consider an optimal solution for [subproblem i]. Either it [uses item i], in which case the rest of it must be an optimal solution to [the smaller subproblem], giving $A[i-1] + v_{i}$; or it does not, in which case it is an optimal solution to [the other smaller subproblem], giving A[i-1]. Since these two cases are exhaustive, the optimum is the better of the two, which is what the recurrence takes."

The phrase doing the work is "exhaustive". You are claiming every optimal solution falls into one of your cases. If it does not, the recurrence is wrong, and that is the only way to lose these marks.

Template, part (c): bottom up and running time

1. Say the fill order so the marker can see the dependencies are already computed: "We compute the entries in the order i = 0, 1, ..., n [and for each i, j = 1 up to B]."

2. Pseudocode. Initialise base cases, nested loops, apply the recurrence, return the answer cell.

3. Running time by counting the loops: "There are n·B entries and each is computed in O(1) time from previously computed entries, so the total running time is O(nB)."

4. If it asks for the actual solution, not just its value, add a second array: "We also store J[i], the choice that achieved the maximum in the recurrence for entry i. To recover the solution, start at i = n and repeatedly follow J backwards, outputting the choice at each step, until i = 0." Then give the four line while loop.

The trap in part (c)

When the question says "compute how many shares to buy from each company", it is asking for the traceback, not just the max value. Students write a perfect table fill and lose 3 or 4 marks because the algorithm never outputs the actual choices. If the question names a thing to output, your pseudocode has to output that thing.

Q3 skeleton: greedy 15 marks · 28 min

The algorithm is usually three lines and you will find it in two minutes. Roughly two thirds of the marks are on the proof, so budget accordingly. Write the algorithm fast and spend the time on the induction.

Template, the algorithm

"Sort the input by [key]. Then repeatedly take the [first / smallest / earliest finishing] remaining item that keeps the solution feasible, and remove everything it conflicts with."

Then the pseudocode, then: "Sorting takes O(n log n) and the single pass does O(1) work per item, so the total running time is O(n log n)." If the question says the input arrives sorted, that becomes O(n) and you should say so explicitly, because that is the "for full credit" bound.

Template, the optimality proof (learn this one by heart)

Claim. "For every i, after the algorithm has processed the first i items, its partial solution Si is contained in some optimal solution."

Base case. "For i = 0, S0 is empty and is contained in every optimal solution."

Inductive step. "Suppose Si-1 is contained in an optimal solution O. There are three cases.

  • If the algorithm does not add item i, then Si = Si-1 and we are done by the hypothesis.
  • If it adds item i and item i is already in O, then Si is still contained in O and we are done.
  • If it adds item i and item i is not in O, we construct a different optimal solution that does contain it. [The exchange.] Let e be [the item of O that conflicts with item i]. Set O' = O minus e plus item i. Then O' is feasible because [reason], and |O'| = |O| so O' is also optimal. Since Si-1 is contained in O and does not contain e, Si is contained in O'."

Conclusion. "Hence the final solution Sn is contained in some optimal solution O. Since no further item can be added to Sn without breaking feasibility, and O is feasible, Sn = O, so the algorithm is optimal."

The one sentence you have to invent

Every line of that proof is boilerplate except "O' is feasible because [reason]". That reason is the entire content of the greedy argument, and it always comes straight from the greedy rule. For earliest finish time: the swapped in interval finishes no later than the one removed, so nothing that fit after e stops fitting. For the shelves problem: the books fit because they fit on greedy's shelf. Find that sentence and the proof writes itself around it.

The other accepted proof shape

Some questions ask instead for induction on the size of the input: solve the first piece greedily, argue an optimal solution agrees with you on that piece, then apply the induction hypothesis to what remains. Both are accepted. Use whichever is cleaner, but say which one you are doing in the first line.

Q4 skeleton: flow, mechanical 10 marks · 15 min

No justification is asked for. This is 10 marks of following a procedure, and it is the single best value question on the paper.

Template

(a) Build the network. Add a source s and a sink t. Direct every original edge from the left side to the right side. Label every single capacity, including the ones that are 1. Say "all capacities are 1" only if that is literally true for every edge.

(b) Run Ford Fulkerson. Write each augmenting path as a node list with its bottleneck:

s, a, B, t   bottleneck 1
s, b, A, t   bottleneck 1
s, c, D, t   bottleneck 1

Then the final flow, edge by edge: f(s,a) = 1, f(a,B) = 1, .... Then, if asked, the matching: M = {(a,B), (b,A), (c,D)}.

(c) The min cut. One sentence and it is always the same one:

"Let A be the set of vertices reachable from s in the residual network Gf, and B = V \ A. Then A = {...} and B = {...}, and the capacity of this cut equals val(f), so it is a minimum cut."

Three ways people throw away these marks
  • Forgetting backward edges in the residual network. If f(u,v) = 3 with capacity 5, the residual has (u,v) with 2 and (v,u) with 3. Augmenting paths are allowed to use the backward one, and on most exam networks the last augmenting path does exactly that.
  • Reading the cut off the original graph. The cut comes from reachability in the residual network, never the original.
  • Only counting forward edges in the cut capacity. c(A,B) sums capacities of edges going from A to B and ignores edges coming back from B to A. It does not subtract them.

Q5 skeleton: flow, modelling 15 marks · 25 min

A word problem about assigning things to other things, with limits on both sides. The network is almost always four layers, and the limits become capacities.

Template

1. Construct the network, in prose, naming every capacity.

"Construct a flow network G' = (V', E') as follows. The vertices are a source s, a sink t, a vertex ui for each [left thing] i, and a vertex vj for each [right thing] j. The edges are:

  • (s, ui) with capacity [the per left thing limit], for each i;
  • (ui, vj) with capacity 1, for each pair that is allowed;
  • (vj, t) with capacity [the per right thing limit], for each j."

2. State the algorithm. "Compute an integral maximum s-t flow f in G' using Ford Fulkerson. Then assign [left thing] i to [right thing] j exactly when f(ui, vj) = 1."

3. Correctness, in two directions. Both are needed for full marks.

"Every valid assignment of size k gives an integral flow of value k: route one unit along (s, ui), (ui, vj), (vj, t) for each assigned pair. Capacities are respected precisely because [the constraint] holds.

Conversely, every integral flow of value k gives a valid assignment of size k: since capacities are integers, Ford Fulkerson returns an integral flow, so each f(ui, vj) is 0 or 1. Flow conservation at ui bounds its assignments by the capacity of (s, ui), and conservation at vj bounds its assignments by the capacity of (vj, t).

Therefore the maximum flow value equals the maximum size of a valid assignment."

4. Running time. "The network has |V'| = O(n + m) vertices and |E'| = O(n + m + L) edges, where L is the total number of allowed pairs. Building it takes O(|V'| + |E'|). Ford Fulkerson with the shortest augmenting path rule (Edmonds Karp) runs in O(|E'|2|V'|), which is polynomial in n + m. Reading off the assignment takes O(|E'|)."

Why integrality is the load bearing word

You are using a continuous object (a flow) to answer a discrete question (an assignment). The bridge is the integrality theorem: if all capacities are integers, Ford Fulkerson terminates with an integral flow. Without that sentence, a max flow could put 0.5 on an edge and "assign half a student to a club", and your correctness proof is broken. Markers look for it.

When you need a fifth layer

If the problem caps the total as well as the per item amounts ("exactly c slots get a TA"), add one extra node t' before t and a single edge (t', t) with capacity c. Every path is then forced through that one edge and the global cap is enforced by it alone.

Q6 skeleton: linear programming 10 marks · 12 min

Two mechanical parts. There is nothing to understand at exam time, only a procedure to apply without slipping. Practice this until it is muscle memory, because it is the cheapest 10 marks on the paper.

Template, part (a): standard form

Target shape, for a maximisation:

max  c₁x₁ + ... + cₙxₙ
s.t. a₁₁x₁ + ... + a₁ₙxₙ ≤ b₁
     ...
     aₘ₁x₁ + ... + aₘₙxₙ ≤ bₘ
     x₁, ..., xₙ ≥ 0

Four moves, applied in this order:

  1. Move every variable to the left. $x_{2} \le 1 - x_{1}$ becomes $x_{1} + x_{2} \le 1$. Do this first, it prevents most sign errors.
  2. Flip every ≥ constraint by multiplying both sides by -1. $2x_{2} \ge x_{1}$ becomes $x_{1} - 2x_{2} \le 0$.
  3. Split every equality into two inequalities, then flip the ≥ one.
  4. Split every free variable. If $x_{1} \in \mathbb{R}$, replace every occurrence of $x_{1}$ with $x_{1}^{+} - x_{1}^{-}$ and add $x_{1}^{+}, x_{1}^{-} \ge 0$. Every occurrence, in the objective too.

If the objective is a min, either negate it into a max, or leave it as a min and use the min standard form, where constraints are ≥. Say which one you are using.

Template, part (b): the dual

From $max c^{T}x, Ax \le b, x \ge 0$ to $min b^{T}y, A^{T}y \ge c, y \ge 0$. Mechanically:

  • max becomes min.
  • One dual variable per primal constraint. m constraints give m dual variables.
  • The old right hand side b becomes the new objective coefficients.
  • The old objective coefficients c become the new right hand sides.
  • The constraint matrix is transposed: the coefficients of $x_{j}$ down the primal constraints become the j-th dual constraint.
  • ≤ becomes ≥. Both variable sets stay ≥ 0.

Then the sentence that is explicitly asked for every time: "The dual variable yi corresponds to the primal constraint [name it]." It is worth marks on its own. Do not skip it.

Sign errors are the only real risk here

Check your answer in ten seconds: the number of dual variables must equal the number of primal constraints, and the number of dual constraints must equal the number of primal variables. If those two counts do not match, you have transposed something wrong. Do this check before moving on.

Q7 skeleton: NP completeness 10 marks · 20 min

Two halves. The first is nearly free and takes three minutes. The second is where the thinking is. Write the free half first even if you cannot see the reduction yet.

Template, half 1: the problem is in NP

Two sentences, always the same two:

"The certificate is [the object being asked for, for example the set R of representatives]. The certifier checks that |R| ≤ k, and that for each club ci, the set Ci contains at least one member of R. This can be done in time O([something obviously polynomial]), so the problem is in NP."

The certificate is the thing the question says "decide if there is a ...". Nothing clever is required and nothing clever is wanted.

Template, half 2: the problem is NP hard

1. Name the source problem and the direction. "We show Vertex-Cover ≤P Representatives. Since Vertex-Cover is NP complete, this shows Representatives is NP hard."

2. Give the reduction as a construction. "Given an instance (G = (V, E), k) of Vertex-Cover, construct an instance of Representatives as follows: for each vertex u of V create a student su; for each edge (u, v) of E create a club with membership set C(u,v) = {su, sv}; keep the same bound k. This takes O(|V| + |E|) time, so it is polynomial."

3. Prove both directions. Both. Half marks for one.

"(⇒) If G has a vertex cover S of size at most k, take R = {su : u ∈ S}. For any club C(u,v), the edge (u,v) is covered, so u or v is in S, so R contains a member of that club. Hence R is a valid set of representatives with |R| ≤ k."

"(⇐) If there is a set of representatives R with |R| ≤ k, take S = {u : su ∈ R}. For any edge (u,v), the club C(u,v) contains a representative, which must be su or sv, so u or v is in S. Hence S is a vertex cover of size at most k."

4. Conclude. "Representatives is in NP and is NP hard, therefore it is NP complete." Write that line. It is the thing the question literally asked for.

The direction, which people reverse every year

To show your problem Y is hard, you reduce a known hard problem X into it: $X \le _{P} Y$. You are saying "if I could solve Y, I could solve X, and X is known to be hard". Reducing Y to X proves only that Y is no harder than X, which is worth nothing. Reduction arrows point from the known hard problem to your new problem.

Picking the source problem in 30 seconds

Match the shape, not the story.

  • "pick a small set that touches every group" → Vertex-Cover or Set-Cover
  • "pick a large set with no two conflicting" → Independent-Set
  • "pick a large set that are all mutually compatible" → Clique
  • "hit a numeric target exactly with a subset" → Subset-Sum
  • "satisfy a list of either-or conditions" → 3-SAT
  • "visit everything once in a sequence" → Hamiltonian-Path or Cycle

The exam hint usually names the shape for you. In the 2024 final it said "this is a type of covering problem", which is the marker telling you to use Vertex-Cover or Set-Cover.

If you run out of time on a question

Write the skeleton with gaps rather than nothing. "The certificate is the set R. The certifier checks |R| ≤ k and that every club contains a member of R." is worth real marks on its own even with no reduction underneath it. Part marks in this course are generous and are awarded per move, so an incomplete answer with the right structure beats a blank page by a wide margin.
