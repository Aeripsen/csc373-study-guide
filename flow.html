Definitions you have to have exactly right

A flow network is a directed graph G = (V, E) with a source s, a sink t, and a capacity c(e) ≥ 0 on every edge.

An s-t flow is a function f: E → ℝ≥0 satisfying:

  • Capacity: 0 ≤ f(e) ≤ c(e) for every edge.
  • Conservation: fin(v) = fout(v) for every v ≠ s, t, where fin(v) sums the flow on edges entering v and fout(v) sums the flow on edges leaving it.

The value is val(f) = fout(s), the total pushed out of the source.

Conservation does not apply at s or t

That is the point of them. Every other vertex is a junction that passes on exactly what it receives. If you find yourself checking conservation at s, you have misread the definition.

The residual network, and the backward edge

Given a flow f, the residual network Gf has the same vertices and, for each edge (u,v) of G carrying flow f(u,v) out of capacity c(u,v), up to two edges:

The rule, memorise it
  • Forward edge (u,v) with residual capacity c(u,v) - f(u,v), present when that is positive. This is spare room.
  • Backward edge (v,u) with residual capacity f(u,v), present when that is positive. This is the flow you are allowed to cancel.
What the backward edge is actually for

It is the algorithm's undo button, and it is the entire reason Ford Fulkerson is correct rather than just a plausible heuristic.

Without it, a greedy path chooser could make an early commitment that blocks the optimum, with no way to recover. The backward edge means a later augmenting path can route flow against an earlier decision, reducing it, in exchange for a better route elsewhere. The net effect is a rerouting, not a reduction, so the value still goes up.

You will see this happen in the animation below: the final augmenting path travels the wrong way down an edge, and the total flow still increases.

Ford Fulkerson, animated end to end

Ford-Fulkerson(G, s, t)
1  f(e) = 0 for every edge e
2  while there is an s-t path P in the residual network G_f
3      b = min residual capacity along P        // the bottleneck
4      augment f by b along P
5  return f

Augmenting by b along P means: for each forward edge of P, add b to its flow; for each backward edge, subtract b from the flow on the corresponding original edge.

Ford Fulkerson, with the residual network underneath

The network on top shows flow / capacity. The residual underneath is what the algorithm actually searches. Watch the last augmenting path: it uses a backward edge.

The three ways people lose these marks
  • Omitting backward edges from the residual. If f(u,v) = 3 and c(u,v) = 5, the residual has (u,v) with 2 and (v,u) with 3. On most exam networks the last augmenting path uses one of these, so leaving them out gives a flow that is not maximum and a cut that does not match.
  • Reading the cut off the original graph. Reachability is computed in the residual network, always.
  • Subtracting backward capacities in the cut. c(A,B) is the sum of c(u,v) over edges with u ∈ A and v ∈ B. Edges going from B back to A contribute nothing at all, they are not subtracted.

Cuts, and reading the min cut off the residual

An s-t cut is a partition of V into (A, B) with s ∈ A and t ∈ B. Its capacity is

c(A, B) = ∑ c(u,v)   over edges (u,v) with u ∈ A and v ∈ B

Forward crossings only. An edge from B to A adds nothing.

How to produce a minimum cut, every time

Run Ford Fulkerson to completion. Then:

"Let A be the set of vertices reachable from s in the residual network Gf, and let B = V \ A. Then c(A,B) = val(f), so (A,B) is a minimum cut."

A always contains s, and never contains t, because if t were reachable there would still be an augmenting path and the algorithm would not have stopped.

Why that cut is saturated, in two lines

Take any edge (u,v) with u ∈ A, v ∈ B. If it had spare capacity, the residual would contain (u,v) and v would be reachable from s, so v would be in A. Contradiction. Hence every edge from A to B is full.

Take any edge (v,u) with v ∈ B, u ∈ A. If it carried flow, the residual would contain the backward edge (u,v), again making v reachable. Hence every edge from B to A is empty.

So val(f) = c(A,B) - 0 = c(A,B). Since every flow is at most every cut, both are optimal.

When the exam asks for a second, different min cut

There is a symmetric construction and it is worth 3 marks when it comes up. Instead of vertices reachable from s, take B' = the vertices that can reach t in the residual network, and A' = V \ B'. That is also a minimum cut, and it is the largest one, while the reachable-from-s version is the smallest. If they differ, you have your two distinct cuts. If they are equal, the minimum cut is unique and you say so.

Max flow min cut

The theorem, and the three equivalent statements

For any flow f in G, the following are equivalent:

  1. f is a maximum flow.
  2. There is no augmenting path in Gf.
  3. There is a cut (A,B) with c(A,B) = val(f).

In particular the maximum flow value equals the minimum cut capacity.

The three implications are short. 1 ⇒ 2: an augmenting path would let you push more. 2 ⇒ 3: that is the reachability construction above. 3 ⇒ 1: weak duality says every flow is at most every cut, so a flow that matches a cut cannot be beaten.

Weak duality in one line, because it appears again in LP

Any unit of flow leaving s must eventually reach t, and to do so it must cross from A to B at some point. So val(f) ≤ c(A,B) for every flow and every cut. That gives an instant certificate: exhibit a cut whose capacity equals your flow's value and you have proved your flow is maximum without any further argument. This is the same certifying idea as LP duality, and max flow min cut is literally a special case of the LP duality theorem.

Integrality, the sentence you need for every Q5

If all capacities are integers, Ford Fulkerson terminates with an integral maximum flow, meaning every f(e) is a whole number.

Why: the flow starts at 0, every bottleneck is a minimum of integers, so every augmentation adds an integer to integers. Induction does the rest.

This is what lets a flow answer a discrete question. Without it, a max flow could put 0.5 on an edge and half-assign a student to a club.

Running time, and why Edmonds Karp exists

Why plain Ford Fulkerson is not polynomial

O(|E| · C) depends on the flow value, not the input size. C is written in log C bits, so this is pseudo-polynomial in exactly the same sense as the O(nB) knapsack table.

The standard bad case: two paths of capacity 1000000 joined by a middle edge of capacity 1. Choose augmenting paths badly and you route through that middle edge every time, alternating direction, pushing one unit per iteration and taking two million iterations on a five edge graph.

Edmonds Karp fixes this by always taking the shortest augmenting path via BFS, which makes the bound depend only on |V| and |E|. When a question asks for a polynomial running time, cite Edmonds Karp, not plain Ford Fulkerson.

Bipartite matching is faster

On a unit capacity bipartite matching network, the max flow is at most n, so plain Ford Fulkerson is already O(|E| · n) = O(mn). Hopcroft and Karp improve it to O(m√n) by augmenting along many short paths at once.

Exam answer, written out

December 2024 Q4. A bipartite graph with left vertices a, b, c, d and right vertices A, B, C, D. Find a maximum cardinality matching using Ford Fulkerson. Three parts, no justification required.

Open for the full written answer

(a) The network. Build G' as follows. Vertices are a new source s, a new sink t, and all of the original vertices. Edges are:

  • (s, x) with capacity 1, for each left vertex x in {a, b, c, d};
  • (x, Y) with capacity 1, directed left to right, for each original edge;
  • (Y, t) with capacity 1, for each right vertex Y in {A, B, C, D}.

All capacities are 1. Draw it and write the 1 on every edge, including the obvious ones. The marker is checking that the capacities are labelled, not that they are surprising.

(b) Running the algorithm. Give each augmenting path as a node list with its bottleneck:

s, a, B, t   bottleneck 1
s, b, A, t   bottleneck 1
s, c, C, t   bottleneck 1
s, d, D, t   bottleneck 1

Then the final flow: f(s,a) = f(s,b) = f(s,c) = f(s,d) = 1, f(a,B) = f(b,A) = f(c,C) = f(d,D) = 1, f(A,t) = f(B,t) = f(C,t) = f(D,t) = 1, and 0 on every other edge.

Then the matching, which is just the middle layer edges carrying flow: M = {(a,B), (b,A), (c,C), (d,D)}, of size 4.

(c) A minimum cut. If every left vertex is saturated, the residual has no edge leaving s, so A = {s} and B = everything else, with capacity 4, matching the flow value.

If the matching is smaller than the number of left vertices, then A is larger: it contains s, every left vertex still reachable, and every right vertex reachable from those. Compute it by running one BFS in the residual from s and listing what you reach.

The check that takes ten seconds and saves the question

Add up the capacities of the edges crossing your cut from A to B. That number must equal your flow value. If it does not, either your flow is not maximum (you missed an augmenting path, probably one using a backward edge) or your cut is wrong. This check is free and it catches essentially every error in this question.

Q4 in ten lines, the whole procedure
  1. Add s and t, direct all edges left to right, label every capacity.
  2. Set all flows to 0.
  3. Find any s-t path in the residual. Write it as a node list.
  4. Its bottleneck is the smallest residual capacity on it. Write that number down.
  5. Add the bottleneck on forward edges, subtract it on backward ones.
  6. Redraw the residual, including backward edges.
  7. Repeat from 3 until no s-t path exists.
  8. Write out the final flow, edge by edge.
  9. A = what is reachable from s in the residual. B = the rest.
  10. Check c(A,B) = val(f). If they differ, go back to step 3.
