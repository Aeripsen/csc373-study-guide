The aid sheet

Everything the exam can ask, in the order you would write it. Copy this by hand and you need nothing else.

Read this before you write a word of it

On the final it is not the instructor who checks your sheet, it is an invigilator sent by the Faculty of Arts and Science, and they are strict. If it is not handwritten on a piece of paper they will make you put it away or take it, and write you up. No printed text, no PDF screen grabs pasted on, nothing that does not look like something you could have written by hand. Students have been badly rattled by this at the start of an exam.

So: copy this out by hand, in pen, on one sheet, both sides. Do it at least two days before the exam, then sit a past paper using the sheet you will actually carry.

Why copying it by hand is not wasted time

Writing it out is itself a full revision pass, and it forces you to decide what matters. What follows is already trimmed to the things that are arbitrary: which way the dual flips, which direction a reduction goes, whether case 3 has a side condition. Anything you can reason out in ten seconds is deliberately not here.

1. Master theorem and divide and conquer

Probably given to you

The instructor has said a statement of the master theorem is provided on the exam sheet, and it was printed on both past midterms. Copy it anyway as insurance, but the log values below matter more, because those are never provided.

Copy verbatim

For $a \ge 1$, $b > 1$,   $T(n) \le a\,T(\lceil n/b \rceil) + f(n)$,   $c = \log_b a$:

$$\begin{array}{lll} \text{case 1} & f(n) = O(n^{\,c-\epsilon}) & \Rightarrow\; T(n) = O(n^{c}) \\[3pt] \text{case 2} & f(n) = \Theta(n^{c}\log^{k} n),\; k \ge 0 & \Rightarrow\; T(n) = O(n^{c}\log^{\,k+1} n) \\[3pt] \text{case 3} & f(n) = \Omega(n^{\,c+\epsilon}) \ \text{and}\ a f(n/b) \le d f(n),\; d < 1 & \Rightarrow\; T(n) = O(f(n)) \end{array}$$

Method: compare $n^{c}$ against $f(n)$. The bigger exponent wins. A tie costs one $\log$.

$$\log_2 2 = 1, \qquad \log_2 3 \approx 1.585, \qquad \log_2 8 = 3, \qquad \log_4 2 = 0.5$$ 
2T(n/2)+O(n)     -> O(n log n)     3T(n/2)+O(n log n) -> O(n^log2(3))
8T(n/2)+O(n^2)   -> O(n^3)         8T(n/2)+O(n^3)     -> O(n^3 log n)
2T(n/4)+O(n)     -> O(n)           3T(n/2)+O(n)       -> O(n^log2(3))

D&C SKELETON
 "Solve(A,l,u) returns [exact contract]"
 <- combine too slow? make the recursion ALSO return sorted order
 base / split / two recursive calls / combine
 correctness: induction on n
 time: T(n) <= aT(n/b)+f(n), then the master theorem sentence

 counting inversions: taking from C adds |B remaining| inversions
 significant inversions (A[i] > 2A[j]): TWO merges, one on a doubled
   copy for counting, one plain for sorting

2. Greedy, and the proof skeleton

Copy verbatim. This is worth about 10 marks a year 
ALGORITHM: sort by [key], take the first item that keeps S feasible,
           remove everything it conflicts with.
TIME: O(n log n) for the sort; O(n) if the input is already sorted (say so).

PROOF.  Claim: for every i, S_i is CONTAINED IN some optimal O.
 base:  S_0 = {} , contained in every optimal solution
 step:  assume S_(i-1) is a subset of an optimal O
   (1) greedy skips i       -> S_i = S_(i-1), done
   (2) takes i, i in O      -> done
   (3) takes i, i NOT in O  -> e = the element of O conflicting with i
                               O' = O - e + i
         O' FEASIBLE BECAUSE [the greedy rule]  <- the only real content
         |O'| = |O| so still optimal;  S_i is a subset of O'
 end:   S maximal + O feasible + S subset of O  =>  S = O   <- DO NOT SKIP

earliest finish time: f_j <= f_k, so swapping in frees space, never takes it
minimising lateness : EARLIEST DEADLINE FIRST, durations are irrelevant
covering a line     : push each choice as far right as it can still reach
The wrong induction, with the counterexample that kills it 
DO NOT prove "greedy on the first i is optimal for the first i" by
assuming that removing the last item from an optimal solution leaves an
optimal subsolution.  THAT IS FALSE.

 shelves, L = 10, thicknesses 5, 2, 2, 5
 an optimal solution: {5} , {2,2,5}   = 2 shelves
 drop the last book:  {5} , {2,2}     = 2 shelves
 but the optimum for 5,2,2 is         = 1 shelf   (5+2+2 = 9)

If you must use this shape, remove THE WHOLE LAST GROUP, not the last item.

3. Dynamic programming

Copy verbatim 
(a) 2-3 marks, ONE SENTENCE. Never leave it blank.
    "For [range], A[i] = the [max/min/number of] [quantity]
     achievable using only [resource]. A[0] = 0. The answer is A[n]."

(b) 6-7 marks. Recurrence + BASE CASES ON THEIR OWN LINE + justify:
    "an optimal solution either does X (-> A[..]+v) or does not (-> A[..]);
     THESE CASES ARE EXHAUSTIVE, so take the better of the two."

(c) 5-7 marks. Fill order (every dependency has a smaller index),
    pseudocode, then "nB entries, O(1) each, so O(nB)".

(d) IF THE QUESTION NAMES AN OUTPUT: second array J[i] = the argmax,
    then walk backwards from n.  <- a lot of (c)'s marks live here

The two shapes. Ask whether the last decision is a yes/no or a where.

$$A[i] = \max\{\,A[i-1],\; A[i-w] + v\,\} \qquad\text{or}\qquad A[i] = \min_{1 \le j \le i}\bigl(A[j-1] + \operatorname{cost}(j,i)\bigr)$$

Left: subset sum, dominoes, weighted intervals. Right: shelves, bundling, optimal BST, and it costs a factor of $n$ more.

Edit distance, the grid every two sequence problem reduces to:

$$E[i][0] = i,\quad E[0][j] = j, \qquad E[i][j] = \min\begin{cases} E[i-1][j] + 1 & \text{delete} \\ E[i][j-1] + 1 & \text{insert} \\ E[i-1][j-1] + \mathbb{1}\{X[i] \ne Y[j]\} & \text{match or substitute} \end{cases}$$

Pseudo-polynomial. $O(nB)$ is not polynomial: $B$ takes only $\log B$ bits, so $O(nB) = O(n\,2^{\log B})$ is exponential in the input size. That is why Subset Sum is NP complete and still has an $O(nB)$ table, with no contradiction.

The invalid recurrence, every single year 
"S[i] = min height for the first i books", then a recurrence asking
"does book i fit on the last shelf?"   IS NOT A RECURRENCE.
S[i-1] is a NUMBER. It does not record what is on its last shelf,
what their total thickness is, or what their maximum height is.

Adding thickness + max height as parameters => exponential array. Do not.

FIX: GUESS THE WHOLE LAST GROUP, not just where the last item goes.

4. Flow mechanics

Copy verbatim

Capacity $0 \le f(e) \le c(e)$.   Conservation $f^{\mathrm{in}}(v) = f^{\mathrm{out}}(v)$ for every $v \ne s,t$.   Value $\operatorname{val}(f) = f^{\mathrm{out}}(s)$.

RESIDUAL, both edges, ALWAYS:
   forward  (u,v) with c(u,v) - f(u,v)     if positive
   backward (v,u) with f(u,v)              if positive

FORD-FULKERSON
 1. all f = 0
 2. find any s-t path in G_f; write it as a node list
 3. bottleneck = the smallest residual on it
 4. ADD on forward edges, SUBTRACT on backward edges
 5. repeat until no s-t path exists

MIN CUT   A = reachable from s in G_f,   B = V \ A
2nd CUT   B' = can reach t in G_f,       A' = V \ B'   (the largest one)
          if A = A' the minimum cut is unique, and say so
$$c(A,B) \;=\; \sum_{\substack{(u,v) \in E \\ u \in A,\; v \in B}} c(u,v) \qquad \text{forward crossings only; } B \to A \text{ contributes } 0$$ 
CHECK: c(A,B) MUST equal val(f). If not you missed an augmenting path,
       probably one that uses a backward edge.

max-flow = min-cut:  f is max  <=>  no augmenting path  <=>  some cut
                     has c(A,B) = val(f)
INTEGRALITY: integer capacities => FF returns an INTEGRAL max flow

Ford-Fulkerson   O(|E| * C)      pseudo-polynomial
Edmonds-Karp     O(|E|^2 |V|)    polynomial   <- cite THIS one
bipartite match  O(mn)

5. Flow modelling

Copy verbatim 
FOUR LAYERS
   s --[per-left limit]--> u_i --[1]--> v_j --[per-right limit]--> t

   the middle edge EXISTS only for permitted pairs. That is how
   "only clubs they applied to" is enforced: a missing edge is an
   absolute prohibition, stronger than any finite capacity.
   a GLOBAL cap c?  -> extra node t', single edge (t',t) of capacity c

ALGORITHM: integral max flow by Edmonds-Karp; assign i to j iff f = 1

CORRECTNESS, BOTH DIRECTIONS (half marks for only one):
  assignment of size k  ->  flow of value k
      route 1 unit per assigned pair; capacities hold because [quote the
      sentence from the question, one per capacity]
  integral flow of value k  ->  assignment of size k
      capacities are integers so FF returns an INTEGRAL flow, so every
      middle f is 0 or 1; conservation at u_i bounds i by c(s,u_i);
      conservation at v_j bounds j by c(v_j,t)
  => max flow = max assignment

TIME: count |V'| and |E'|, then O(|E'|^2 |V'|), polynomial in n+m

BIPARTITE MATCHING: add s and t, orient left to right, ALL capacities 1
WANT THE CUT NOT THE FLOW: image segmentation. An s-t cut IS a binary
   labelling.  (s,u) cap a_u ;  (u,t) cap b_u ;  (u,v),(v,u) cap p_uv

6. Linear programming

Copy verbatim
$$\begin{array}{ll} \textbf{PRIMAL} & \textbf{DUAL} \\[3pt] \max\; c^{\mathsf T}x & \min\; b^{\mathsf T}y \\ Ax \le b & A^{\mathsf T}y \ge c \\ x \ge 0 & y \ge 0 \\[3pt] m \text{ constraints} & m \text{ variables} \\ n \text{ variables} & n \text{ constraints} \end{array}$$ 
max pairs with <= ;  min pairs with >= .  Both have all variables >= 0.

TO STANDARD FORM, IN THIS ORDER
 1. variables to the left, constants to the right
 2. flip >= by multiplying the whole row by -1
 3. equality -> two inequalities, then flip the >= one
 4. free x -> x+ - x-, both >= 0, EVERYWHERE INCLUDING THE OBJECTIVE

free primal variable       <-> equality dual constraint
equality primal constraint <-> free dual variable

SAY IT: "the dual variable y_i corresponds to the primal constraint ___"
CHECK:  #dual vars = #primal constraints;  #dual constraints = #primal vars

Absolute values. Only valid when the objective pushes the new variable down.

$$\min \sum_i \lvert g_i(x)\rvert \;\longrightarrow\; \min \sum_i e_i \ \text{ s.t. } \ e_i \ge g_i(x),\; e_i \ge -g_i(x)$$ $$\min \max_i \lvert g_i(x)\rvert \;\longrightarrow\; \min t \ \text{ s.t. } \ t \ge g_i(x),\; t \ge -g_i(x) \quad(\text{one shared } t)$$

One $e_i$ each gives the sum of errors. One shared $t$ gives the worst error. That single difference has been examined both ways.

Duality theorem. Exactly one of these holds: both feasible with equal finite optima; one unbounded and the other infeasible; both infeasible. Max flow min cut is a special case.

What the LP graders actually mark down 
1. Say what your variables mean IN ENGLISH before any constraint.
2. c_j, d_j, w_ij are CONSTANTS. Never in the non-negativity constraints.
3. The dual is NOT the negative of the primal.
4. NO primal variable may appear in the dual (it stops being linear).
5. m + n dual variables, NOT m * n.
6. Derive by comparing the coefficient of ONE x at a time. Since x_ij >= 0
   it is enough that y_i + z_j >= w_ij. Do not sum all the inequalities.

7. NP completeness

Copy verbatim
$$X \in \mathrm{NP} \iff \exists\ \text{poly-time } B,\ \text{poly } p:\quad x \in X \iff \exists\, y,\ |y| \le p(|x|),\ B(x,y) = \text{Yes}$$ $$X \le_P Y \iff \exists\ \text{poly-time } R:\quad x \in X \iff R(x) \in Y$$ 
NP-hard      : Y <=p X for every Y in NP   (need not itself be in NP)
NP-complete  : in NP AND NP-hard
Cook-Levin   : Circuit-SAT and 3-SAT are NP-complete

TO PROVE Y IS NP-COMPLETE
 1. certificate + certifier, two sentences   (Y in NP, ~3 marks, nearly free)
    "the certificate is [the object]; the certifier checks [the size] and
     [the defining property], in polynomial time"
 2. name the source and the direction:  X <=p Y   X IS THE KNOWN HARD ONE
 3. the construction, as bullets, + "this takes polynomial time"
 4. forward : Yes for X   => Yes for R(x)
 5. reverse : Yes for R(x) => Yes for X       BOTH, or half marks
 6. "in NP and NP-hard, therefore NP-complete"   <- write this line

THE ARROW POINTS FROM THE KNOWN HARD PROBLEM INTO YOURS.
Your reduction takes a VERTEX-COVER instance IN and puts YOUR problem OUT.

MAY REDUCE FROM (confirmed by course staff):
  3-SAT, Subset-Sum, Independent-Set, Vertex-Cover,
  Set-Cover, 3-Colouring, BILP
  stuck? 3-SAT works in most cases
$$S \text{ independent in } G \iff V \setminus S \text{ is a vertex cover} \iff S \text{ is a clique in } \overline{G}$$

So an independent set of size $\ge k$ exists exactly when a vertex cover of size $\le n-k$ does.

MATCH THE SHAPE, NOT THE STORY
 small set touching every group  -> Vertex-Cover / Set-Cover
 large set, no two conflicting   -> Independent-Set
 large set, all compatible       -> Clique
 hit a numeric target exactly    -> Subset-Sum
 a list of either-or conditions  -> 3-SAT
 visit everything exactly once   -> Hamiltonian Path / Cycle

"why does my O(nP) algorithm not prove P = NP?"
 -> polynomial means polynomial in the number of BITS. P takes log P bits,
    so O(nP) is exponential in the input size. Pseudo-polynomial.

The traps, in the instructor's own words

This is what the grader feedback actually said, posted to the class to prepare people for the final. If your sheet has room for nothing else, it has room for this.

Copy verbatim, small, in a corner 
GREEDY  show the partial solution EXTENDS TO some optimal solution.
        Not that every optimal solution matches greedy (usually false).

DP      guess the WHOLE last group. A number cannot remember what is
        on its last shelf.

FLOW    the integrality sentence, or the correctness proof is broken.
        Backward edges in the residual. Read the cut off the RESIDUAL.

LP      variables in English first. Constants are not variables.
        m+n dual variables, not m*n.

NP      the arrow points FROM the known hard problem INTO yours.
        Both directions of the correctness proof.

ALL     state the running time. Give the base cases. Answer the thing
        the question literally asked for: the traceback, the assignment,
        which dual variable corresponds to which constraint.

What to leave off, and the physical layout

These waste space
  • Full pseudocode for algorithms from class. You are never asked to reproduce mergesort or Ford Fulkerson verbatim, only to apply or adapt them.
  • Worked examples. They eat enormous space and the exam's numbers will differ anyway.
  • Definitions you understand. What a matching is, what a cut is, why the backward edge exists. If you could explain it to someone, you do not need it written down.
  • Big-O rules and log identities.
  • The proof of max flow min cut. The three equivalent statements are worth a line, the proof is not.

The test for every line: "if this were not here, would I get it wrong, or would I just be slower?" Write down the things you would get wrong. Being slower is survivable.

How to lay it out on the paper

Side 1, the reference half. The plan in the top corner. The master theorem with the four log values. The LP block: standard form, the dual, the four conversion moves, the two modelling tricks. The NP block: the two definitions, the six step proof, the source problem list, the independent set identity.

Side 2, the skeleton half. The greedy proof. The DP four parts and the two shapes. Flow mechanics. Flow modelling with both correctness directions. Then squeeze the trap list into whatever is left, in the smallest handwriting you can still read.

Reference on one side, skeletons on the other, so under pressure you always know which way to flip.
